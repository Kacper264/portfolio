# Portfolio de Kacper264

Bienvenue sur mon portfolio personnel, réalisé avec **Rust / WASM** et le framework Yew, accompagné d’un back-end en Go.  
Le projet est actuellement sur la branche `preprod`.

## 🚀 Aperçu & mise en ligne  
Voir l’application en ligne : [https://portfolio-kacper-preprod.netlify.app/](https://portfolio-kacper-preprod.netlify.app/)

---

## 🧩 Technologies principales  
- Langage : Rust  
- Front-end : Yew (WebAssembly)  
- Back-end : Go (REST ou WebSocket selon besoins)  
- Styles : SCSS/CSS moderne  
- Build : Trunk pour compiler le WASM + bundler  
- Déploiement : Netlify (front) + éventuellement hébergement Go (back)

---

## 📁 Structure du dépôt
